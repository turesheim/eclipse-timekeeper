Your calendar

Using the calendar

Drag empty space to select a new work-session interval, then review the title, client and times before saving. On touchscreens, turn on Select time range first; turn it off to scroll normally. Escape cancels a selection. You can also select a day/time and choose Record work session to enter times with the keyboard. Strips use the client’s color and show the work session title; task cards list recorded activities. Drag a strip to move it, or its top/bottom edge to resize. Moving preserves duration and leaves activities unchanged. With a strip focused, arrow keys move it and Ctrl/Cmd+C copies it. Select a day and use Ctrl/Cmd+V to paste a separate session without its activities.

The clocks change this week. Repeated times have an extra row; shaded slots do not occur on that day.
