Timekeeper for Eclipse

This is an Eclipse software repository. To install this version, open Help > Install New Software… > Add… in Eclipse and paste this page's address into Location.

Select Timekeeper for Eclipse for project, task and activity management. Select Timekeeper Mylyn integration as well to track Mylyn tasks. Timekeeper 2.0 requires Eclipse 2026-09 (4.41) and Java 21. Keep the Eclipse 2026-09 software site enabled so Eclipse can resolve dependencies.

For future stable updates, use:

https://turesheim.github.io/eclipse-timekeeper/updates/

You can also download timekeeper-p2.zip from GitHub Releases and select Add… > Archive….
